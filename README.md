# Movie Finder

Android app to browse and search movies, filter by genre, read details, save a watchlist and share a movie. Data comes from TMDB.

## Setup

1. Install packages: `npm install`
2. Copy `.env.example` to `.env` and put your TMDB v3 API key in it.
3. Start an Android emulator, or connect a phone with USB debugging (`adb devices` must list it).
4. Run: `npx expo start --android`
